How do I start playing?

Download the launcher, run it, and it fetches the latest game client for you. Then create an account on the start screen, pick a class, and you're in.

Is it free?

Yes. The game is free to play.

Windows says “Windows protected your PC”.

The game isn't code-signed yet. Click More info, then Run anyway.

Can I play on Linux or Mac?

The client is a Windows build. Linux players run it through Wine or Proton. Ask in the Discord if you get stuck.

How do I pick things up?

Loot is picked up automatically when you walk over it. You can turn that off in Options and use Space instead.

My gear is breaking!

Gear wears down as you fight. Visit a repair shop and press R to fix everything before it breaks.

Where do I report bugs or suggest ideas?

In the Discord. Screenshots (F12) help a lot.
